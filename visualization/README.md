# Offline Laplace shape explorer

Extract both files together and open index.html. The profiles show (p₁/p₀−1)/t across x, where t is inverse scale and the two mixing laws are a central point mass and a balanced endpoint mixture on [−1,1]. Teal identifies the interior, blue the tails. Select a scale to emphasize it, and rotate the view. The displayed probabilities and ratios use the analytic formulas with floating-point display rounding.
